# Stroke CT Visual Refresh Design

## Goal

ปรับภาพความรู้ใน Team 4 แผน 03 ให้ดูเป็นงานทางการแพทย์มากขึ้น โดยแยกภาษาภาพให้ชัดเจน:

- ประเภท Stroke อธิบายด้วยภาพหลอดเลือดสมอง
- ตำแหน่งรอยโรคอธิบายด้วย CT สมองจริงที่วงตำแหน่งไว้
- ภาพปกใช้ผู้ชายและคงโทนโฮโลแกรมของแผนปัจจุบัน

## Approved Visual Direction

### 1. Stroke Type

สร้าง atlas สามช่องขนาดและมุมมองสม่ำเสมอ:

1. เส้นเลือดสมองตีบหรืออุดตัน: เห็นหลอดเลือดและจุดอุดตันชัดเจน
2. เส้นเลือดสมองแตก: เห็นผนังหลอดเลือดแตกและเลือดออกเฉพาะจุด
3. ยังไม่ทราบประเภท: แสดงหลอดเลือดสมองโดยไม่ระบุพยาธิสภาพ

ภาพส่วนนี้เป็น medical illustration ไม่ใช่ CT เพราะหน้าที่คืออธิบายกลไกของหลอดเลือด

### 2. Lesion Location

ใช้ภาพ CT สมองจริงแบบ anonymized และมีสิทธิ์ใช้เชิงพาณิชย์หรือใช้ในสื่อธุรกิจได้ตามเงื่อนไขใบอนุญาต ภาพแต่ละช่องต้อง:

- เป็น axial non-contrast head CT
- ใช้ CT ที่มีรอยโรคจริงเมื่อมีแหล่งภาพและใบอนุญาตเหมาะสม
- หาก CT ไม่เห็นรอยโรคชัด โดยเฉพาะ ischemic stroke ระยะแรกหรือตำแหน่งก้านสมอง ให้ใช้ CT จริงเป็นภาพอ้างอิงและวงเฉพาะบริเวณโดยประมาณ ห้ามทำให้รอยโรคปลอมดูเหมือนสิ่งที่เห็นใน CT
- วงรอยโรคหรือบริเวณอ้างอิงด้วยเส้นบางที่มองเห็นชัด แต่ไม่บดบังรายละเอียด CT
- ใช้สีฟ้าอมเขียวสำหรับ ischemic lesion และสีแดงอมส้มสำหรับ hemorrhagic lesion
- ไม่มีชื่อผู้ป่วย เลขโรงพยาบาล วันที่ตรวจ หรือข้อมูลระบุตัวตน
- แสดงเฉพาะภาพที่ตรงกับข้อมูลผู้ใช้ ไม่แสดง atlas ทั้งชุดพร้อมกัน

ข้อความใต้ภาพ:

> ภาพ CT ตัวอย่างและวงตำแหน่งโดยประมาณ ไม่ใช่ภาพ CT ของคุณ ตำแหน่งจริงควรตรวจสอบจากใบสรุปการรักษาหรือแพทย์ผู้ดูแล

กรณีไม่ทราบตำแหน่ง ใช้ CT ปกติที่ไม่วงรอยโรคและไม่คาดเดาจากอาการ

## Source And Licensing Rules

- ใช้เฉพาะไฟล์ที่ระบุใบอนุญาตระดับไฟล์ชัดเจน เช่น Public Domain, CC0, CC BY หรือ CC BY-SA ที่อนุญาตการใช้งานตามวัตถุประสงค์นี้
- ไม่ใช้ภาพจาก Radiopaedia, เว็บโรงพยาบาล, งานวิจัย หรือ dataset ที่จำกัดเฉพาะ non-commercial โดยไม่มีสิทธิ์เพิ่มเติม
- เก็บ source URL, creator, license, และรายการการดัดแปลงของทุกภาพไว้ใน attribution manifest
- หากไม่มีภาพจริงที่สิทธิ์และตำแหน่งเหมาะสม จะไม่ใช้ภาพใกล้เคียงแล้วอ้างว่าเป็นตำแหน่งนั้น

## Cover Image

คง `plan-stroke-arm-leg.png` ปัจจุบัน เพราะเป็นผู้ชายและมีองค์ประกอบเดียวกับทีมภาพที่อนุมัติแล้ว ได้แก่การฝึกเดินในบ้าน นักกายภาพอยู่ด้านหลัง และเส้นโฮโลแกรมตามแขนขา

## UI Behavior

- ไม่เปลี่ยน layout ที่อนุมัติแล้ว
- เปลี่ยนเฉพาะ asset และคำอธิบายใต้ภาพตำแหน่ง
- `strokeType`, `strokeHemisphere`, และ `strokeLesion` ยังคงควบคุมภาพ selected-only เดิม
- ปุ่ม `แก้ไขข้อมูล` ยังคงทำงานเหมือนเดิม
- ภาพชนิดโรคและตำแหน่งใช้เพื่อให้ความรู้และข้อควรระวังเท่านั้น ไม่เปลี่ยนท่าออกกำลังกาย

## Acceptance Criteria

- ภาพประเภทแสดงกลไกของหลอดเลือด ไม่ใช้สมอง 3D แบบเดิม
- ภาพตำแหน่งใช้ CT จริงและวงรอยโรคหรือบริเวณอ้างอิงอย่างซื่อสัตย์ตามสิ่งที่เห็นในต้นฉบับ
- ไม่มีข้อมูลผู้ป่วยหรือ metadata ที่ระบุตัวตน
- มี attribution ครบตามใบอนุญาต
- ภาพปกเป็นผู้ชาย
- หน้ามือถือไม่มี horizontal overflow และภาพไม่ถูกครอปผิดตำแหน่ง
- selected-only switching และแบบประเมินเดิมผ่าน regression tests
